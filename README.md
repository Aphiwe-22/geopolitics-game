## Tech Stack
- **Frontend:** React (Vite), Axios, React-Simple-Maps (D3.js)
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
- **AI Integration:** Google Gemini API (for dynamic battle commentary)

## Features
- **Dynamic Map:** Interactive SVG world map rendering only the 10 countries in play.
- **Turn-Based Combat:** Custom dice-rolling engine based on classic Risk rules (attacker must leave 1 soldier behind, dice are paired).
- **NPC Automation:** AI-driven NPCs that automatically take turns, attack, and reinforce.
- **Fast-Forward:** A toggle to speed up NPC turns for quicker gameplay.
- **Troop Transfers:** Move soldiers between conquered territories.
- **AI Commentary:** Real-time, epic battle narratives generated by Gemini based on the dice outcomes.
- **Analytics:** Hamburger menu - In-game menu displaying battle history, conquests, and soldier losses.

## How to Run Locally

### Prerequisites
- Node.js installed
- A MongoDB Atlas account and connection string
- A Google Gemini API key in the `.env` file

### 1. Backend Setup
```bash
cd server
npm install

Create a .env file in the server folder and add your credentials:

env
PORT=5000
MONGO_URI=your_mongodb_connection_string
GEMINI_API_KEY=your_google_gemini_api_key
Start the backend server:

bash
npm run dev
2. Frontend Setup

Open a new terminal window and navigate to the client folder:

bash
cd client
npm install
npm run dev
The application will be running locally at http://localhost:5173.

How to Play

Enter the access code (warroom2027).
Select your commander avatar, enter your name, and choose your starting country.
Click Attack Mode to select an enemy country and roll the dice to attack.
Click Transfer Mode to move soldiers between your own countries.
Click End Turn when you are finished, and the NPCs will automatically take their turns.
Open the War Analytics menu (Hamburger icon) to view your battle history and stats.
Conquer all 10 countries to win!
